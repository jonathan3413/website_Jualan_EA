1. MEMAHAMI ISTILAH DASAR IT

  • Node.js: Program di komputer yang bertugas menjalankan kode JavaScript di luar browser (menjadi server backend).
  • npm: Alat bantu pendownload pustaka/perpustakaan kode yang dibutuhkan oleh Node.js.
  • Database: Tempat menyimpan data client, nomor lisensi, dan log secara permanen.
  • REST API: Jalur komunikasi antara EA MetaTrader 5 dan Server website melalui protokol internet (HTTP/HTTPS).
  • Localhost: Alamat server di komputer sendiri (misal: http://localhost:3000).
  • WebRequest: Fitur di MetaTrader 5 yang mengizinkan EA mengirim pesan ke internet/server untuk mengecek lisensi.
  • .mq5: File kode mentah EA yang dibuka di MetaEditor.
  • .ex5: File program EA hasil kompilasi siap pakai yang diberikan kepada client trading.

2. PERSIAPAN & INSTALL NODE.JS

  1. Buka website resmi Node.js di browser: https://nodejs.org
  2. Download versi LTS (Recommended for Most Users).
  3. Buka installer yang terdownload dan klik tombol Next sampai selesai.
  4. Buka Command Prompt (CMD) di Windows atau Terminal di Mac, lalu ketik perintah berikut untuk memastikan Node.js terinstal:
node -v

Hasil yang diharapkan: Muncul versi Node.js (contoh: v20.11.0).

3. MENJALANKAN SERVER LOKAL

Ikuti langkah berikut untuk menjalankan server di komputer Anda:

  1. Buka folder tempat project ini berada.
  2. Klik kanan di area kosong folder → Pilih Open in Terminal atau Open Command Window Here.
  3. Ketik perintah ini untuk mendownload pustaka pendukung:
npm install

Penjelasan: Perintah ini membaca file package.json dan mendownload semua pustaka otomatis.

4. Jalankan server lokal dengan perintah:

npm run dev

Hasil yang diharapkan: Muncul pesan tulisan neon cyan di terminal:
⚡ EA LICENSE MANAGEMENT SERVER ACTIVE ON PORT 3000
Local URL: http://localhost:3000

4. MENGGUNAKAN WEBSITE DASHBOARD ADMIN

  1. Buka browser (Google Chrome atau Edge), lalu ketik alamat: http://localhost:3000
  2. Halaman Login Admin akan muncul. Gunakan akun demo berikut:
    • Username: admin
    • Password: admin123
  3. Setelah login, Anda masuk ke Command Center.
  4. Cara Membuat Client & Lisensi Baru:
    • Klik menu [3.0] CREATE CLIENT.
    • Isi Nama Client (contoh: Ahmad Sudirman).
    • Isi MT5 Account ID (contoh: 12345678). Note: Harus sesuai dengan nomor login account MT5 client.
    • Pilih Produk EA (contoh: EA_STRADDLE).
    • Pilih Durasi (Minimal 3 Bulan / 90 hari).
    • Klik tombol GENERATE & ACTIVATING CLIENT LICENSE NOW.

5. UPLOAD SOURCE CODE KE GITHUB

Agar server dapat di-deploy gratis di internet, upload kode ke GitHub:

  1. Buat akun gratis di https://github.com
  2. Klik tombol + New Repository di GitHub. Beri nama misal: ea-license-system. Pilih Public atau Private, lalu klik Create Repository.
  3. Di folder komputer Anda, jalankan perintah ini urut di Terminal/CMD:
git init
git add .
git commit -m "Initial EA License System commit"
git branch -M main
git remote add origin https://github.com/USERNAME_ANDA/ea-license-system.git
git push -u origin main
PENTING (KEAMANAN): File .gitignore sudah otomatis dipasang sehingga file rahasia .env dan password Anda TIDAK AKAN ikut ter-upload ke GitHub.

6. MEMBUAT DATABASE POSTGRESQL GRATIS

Vercel membutuhkan database cloud permanen agar data client Anda aman disimpan:

  1. Buka penyedia PostgreSQL gratis: Neon.tech atau Supabase.
  2. Daftar akun gratis menggunakan akun GitHub Anda.
  3. Buat Project Baru bernama ea-license-db.
  4. Copy string koneksi (Connection String) PostgreSQL yang diberikan. Contoh:
    postgres://username:password@ep-cool-name.neon.tech/neondb?sslmode=require

7. DEPLOY SERVER KE VERCEL (HOSTING GRATIS)

  1. Buka Vercel.com dan Login menggunakan akun GitHub Anda.
  2. Klik tombol Add New Project → Pilih repository GitHub ea-license-system.
  3. Di bagian Environment Variables, masukkan 2 variabel berikut:
    • Nama: DATABASE_URL | Value: (String PostgreSQL dari Neon.tech di atas)
    • Nama: JWT_SECRET | Value: kunci_rahasia_bebas_12345
  4. Klik Deploy dan tunggu 1-2 menit.
  5. Setelah selesai, Vercel memberikan URL domain gratis, contoh:
    https://ea-license-system.vercel.app

8. KONFIGURASI WEBREQUEST DI METATRADER 5

WAJIB UNTUK CLIENT: Tanpa langkah ini, MetaTrader 5 akan memblokir komunikasi internet EA dan lisensi akan gagal terverifikasi!
  1. Buka MetaTrader 5 di komputer client.
  2. Klik menu Tools → Options (atau tekan Ctrl + O).
  3. Pilih tab Expert Advisors.
  4. Centang kotak: "Allow WebRequest for listed URL:"
  5. Klik dua kali pada baris kosong di bawahnya, lalu masukkan URL Server Vercel Anda:
    https://ea-license-system.vercel.app
    (Jika menguji di komputer sendiri gunakan: http://localhost:3000)
  6. Klik OK.

9. MEMASANG & MENGUJI EA CLIENT DI MT5

  1. Buka MetaEditor (tekan F4 di MetaTrader 5).
  2. Buka file LicenseTestEA.mq5 yang ada di folder project.
  3. Klik tombol Compile (F7). MetaEditor akan menghasilkan file LicenseTestEA.ex5.
  4. Pasang EA pada grafik/chart mana saja di MT5.
  5. Isi Input EA:
    • InpServerURL: https://ea-license-system.vercel.app
    • InpProductCode: EA_STRADDLE
  6. Periksa tab Experts / Journal di bagian bawah MT5:
    [LICENSE VALID] Account 12345678 | Product: EA_STRADDLE | Status: ACTIVE | Expiry: 2026-11-11 | Days Left: 92

10. MEMPERPANJANG LISENSI & BACKUP DATABASE

Memperpanjang Masa Aktif (Extend License):

  • Di Website Dashboard → Buka menu [2.0] CLIENTS.
  • Klik ikon Jam 🕒 pada baris client.
  • Pilih durasi perpanjangan (1 bulan, 3 bulan, 6 bulan, atau 12 bulan).
  • Jika lisensi masih aktif, perpanjangan ditambahkan dari tanggal kadaluarsa lama. Jika sudah kadaluarsa, dihitung dari tanggal hari ini.

Backup Data: Buka menu [8.0] SETTINGS → Klik DOWNLOAD DATABASE BACKUP (.JSON).

11. TROUBLESHOOTING (PENANGANAN MASALAH UMUM)

  • Error MQL5 Code 4014: WebRequest belum diizinkan. Buka MT5 → Tools → Options → Expert Advisors → Allow WebRequest for listed URL.
  • Status ACCOUNT_NOT_REGISTERED: Nomor akun MT5 client belum dimasukkan di website admin. Masukkan nomor akun MT5 di menu Create Client.
  • Status LICENSE_EXPIRED: Masa berlaku lisensi telah habis. Buka menu Clients → Klik Extend License.
  • Status LICENSE_BLOCKED: Client diblokir oleh admin. Klik tombol Unblock/Activate di menu Clients.
  • Grace Period (Server Offline): Jika server sementara tidak bisa dihubungi, EA tetap mengizinkan trading selama 24 jam (Grace Period) berdasarkan verifikasi valid terakhir.
